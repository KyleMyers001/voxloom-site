Release notes for Voxloom, taken from the GitHub release. Voxloom is a work in progress.

2026-11-03 · BETA

Voxloom v0.2.0

This build is signed with a Developer ID and notarized by Apple.

What’s changed

  • Move marketing website to voxloom-site (#138)
  • BUS-139: trim trailing silence before Whisper to stop hallucinated "Thank you" (#132)
  • Keep soft trail-offs the trailing-silence trim cut (BUS-143) (#137)
  • ci(cleanup-worker): stop CMake probing for OpenSSL (fixes red main on macOS) (#139)
  • test(worker): widen the prewarm preemption time bound for slow CI runners (#141)
  • ci(release): stop CMake probing for OpenSSL in the macOS worker build (#140)
  • feat(shortcut): lone-key tokens and recorder capture (BUS-46 slice 1) (#142)
  • BUS-46 slice 2: lone-key state machine and macOS listen-only tap (not wired) (#143)
  • BUS-46 slice 3: wire the lone-key shortcut (arm from settings, edges into the gesture machine, fix L4) (#144)
  • BUS-156: Copied, press ⌘V when Copy happens in a terminal (#145)
  • chore: bump version to 0.2.0 (#146)
  • feat: paste dictation into WezTerm and other terminals (BUS-157) (#147)

Known limitations

  • macOS only (minimum macOS 13.1 (Ventura)); Windows and Linux are not supported yet.
  • No auto-update; download new versions from the Releases page.
  • The Whisper model is not bundled; download it separately.
