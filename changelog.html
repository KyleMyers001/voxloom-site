Release notes for Voxloom, taken from the GitHub release. Voxloom is a work in progress.

2026-11-03 · BETA

Voxloom v0.2.0

This build is signed with a Developer ID and notarized by Apple.

What’s changed

  • Moved the marketing website into its own repository, voxloom-site (#138)
  • Fixed hallucinated "Thank you" text on silence at the end of a recording: trailing silence is now trimmed before Whisper (#132)
  • Soft trail-offs at the end of a recording are no longer cut off by the trailing-silence trim (#137)
  • Settings can now record a single key (Right ⌥, ⌃, ⌘ or ⇧, or F13–F19) as the shortcut (#142)
  • Added the macOS key listener that single-key shortcuts use (#143)
  • A single key can now be used as the dictation shortcut (#144)
  • When dictation falls back to Copy in a terminal app, the message now reads “Copied, press ⌘V” (#145)
  • Dictation can now be pasted into WezTerm, Alacritty, kitty, Ghostty and iTerm2 (with Clipboard fallback on) (#147)

Known limitations

  • macOS only (minimum macOS 13.1 (Ventura)); Windows and Linux are not supported yet.
  • No auto-update; download new versions from the Releases page.
  • The Whisper model is not bundled; download it separately.
